# صديقك الذكي — نسخة الويب

نسخة المتصفح من تطبيق «صديقك الذكي» للآيفون والآيباد والكمبيوتر وأي جوال:
معلم صوتي لطيف يشرح للطالب دروسه من صفحة كتابه، بصوت Gemini.

**الرابط:** https://mswsa99-ship-it.github.io/smart-friend-web/

- كل ولي أمر يربط حساب Gemini الخاص به؛ الرمز يُحفظ مشفّرًا على جهازه فقط.
- لا خادم ولا قاعدة بيانات: الصفحة تتصل بـ Google مباشرة من جهاز المستخدم.
- على الآيفون/الآيباد: سفاري ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## التطوير
- `npm test` يشغّل الاختبارات (منقولة من اختبارات تطبيق أندرويد).
- كل دفع إلى `main`: الاختبارات أولًا، وإن نجحت تُنشر الصفحة تلقائيًا ويصل التحديث للمستخدمين.
